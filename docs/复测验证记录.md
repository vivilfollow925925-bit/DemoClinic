## 使用与边界

更新后的代码已放入 `DemoClinic主工作流.ipynb`。重新打开最新版 Notebook，先运行第1步解包，再运行第12步；若当前内核仍保留 CONFIG 和 RUN，不需要重跑模型体验。内核已经重启时，还需恢复本轮配置和运行目录。

默认 `CONFIG["assertion_timeout_ms"]` 为2000，`CONFIG["verification_timeout_seconds"]` 为600。页面更慢时可以调整；超过等待时间仍可能是页面尚未完成，不能由此证明所有异步情况都能正确判定。

定位证据不足、页面结构或业务内容发生不可确认的变化时仍会阻塞。这是保守停止，不保证任何ID变化都能自动恢复。旧记录首次建立指纹不能证明之前的源码未被改动。

异常恢复覆盖可捕获的运行错误；不承诺多文件发布在突然断电或强制结束进程时具有数据库式事务保证。强制结束内核可能留下 `.verification.lock`，确认没有复测进程后方可删除。Python/JavaScript文件语法检查不等同完整构建，也不覆盖HTML内联脚本的完整静态分析。

本次不是四个实验样本的全量重测，不替代模型体验覆盖评估，也不据此重新认证历史报告。不能保证穷尽所有浏览器、框架和页面行为。
