# 词间 · 智能单词背诵助手

## 项目用途与目标用户
面向需要维护个人词库、按日期复习和检查拼写的中文英语学习者。网站支持词书管理、单词卡片、CSV/JSON 导入、查找筛选、翻卡背诵、到期复习、拼写考察、错词重练和学习统计。“智能”仅指固定间隔规则，不使用大模型，不宣称具有经过验证的个性化学习效果。

## 启动与测试数据
在本目录打开终端：

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

浏览器访问 http://127.0.0.1:8000/ 。无需 npm、网络资源、API、数据库或账号。建议使用现代 Chrome / Edge，启用 JavaScript 和 localStorage。请使用 HTTP 启动，不以双击文件模式作为验收环境。

初始模拟日期固定为 **2026-11-19**，不自动跟随系统日期。右上角可推进一天或输入指定日期（2020-01-01 至 2099-12-30），所有计划、到期判断和统计使用同一模拟日期。向后调整日期不会删除历史作答；同一天已经学习过的卡片不再调整计划。

## 功能与正常规则
- 卡片包含单词、释义、例句、标签。单词与释义必填，字段最多 300 字符，标签使用英文逗号分隔。创建、编辑时去除首尾空格，保留内部内容。编辑不重置学习计划。
- 可创建、切换、重命名、删除词书；名称去除首尾空格后非空且唯一，最长 40 字符，至少保留一本。删除词书会删除其中全部卡片，必须确认；历史作答记录保留。删除卡片同样需要确认。切换词书或删除卡片会结束当前练习，需重新开始。
- 词书选择同时限定查找与新一轮练习范围。搜索单词或释义，英文忽略大小写；标签精确匹配；已掌握是 4 级，学习中是 0–3 级，未学习是未作答且 0 级。
- 导入到当前词书：UTF-8 CSV（带表头）或 JSON 对象数组，1–200 行。必填字符串字段 word、meaning；可选字符串字段 example、tags。任一行不合法时整批禁止提交；预览不写入数据。CSV 支持双引号、字段内逗号和换行。未知字段忽略。
- 示例见 examples/sample.csv 与 examples/sample.json，也可在导入弹窗下载。同词书以去首尾空格、忽略大小写后的单词判重；可选跳过或覆盖内容。覆盖保留原卡片标识、级别、日期。不同词书允许相同单词。
- 整本背诵包括当前词书所有卡片，不受词库搜索或标签筛选影响。翻卡显示释义和例句，作答后自动进入下一张；重复点击开始会新建一轮。
- 到期复习包含今日到期和逾期卡片，不含未安排的新卡。没有卡片时显示完成/空状态。

### 复习间隔与统计口径

|新级别|0|1|2|3|4（已掌握）|
|---|---|---|---|---|---|
|间隔天数|1|1|3|7|14|

新卡 0 级且无到期日。当日首次作答：认识或拼写正确升一级，最高 4；模糊降一级，最低 0；不认识或拼写错误回到 0。到期日 = 当前模拟日期 + 更新后级别间隔。逾期按实际作答日重新计算，不按旧到期日补算。

同卡同日再次作答只记录结果，不改变级别或计划；即使先推进再返回同一天也适用。拼写忽略大小写和首尾空格，内部空格、标点必须一致；非空输入才可提交。错词重练结束后的待重练名单只保留本次仍错的词。

统计覆盖全部词书：今日学习量为当日不同卡片数；正确率为当日“认识/拼写正确”次数除以全部作答次数，四舍五入为整数百分比，模糊算非正确；掌握数量为现有 4 级卡片数；连续天数为截至模拟今天连续有作答的天数，今天未作答为 0。删除卡片后历史日志保留，仍计入对应日期学习统计。

自动保存词书、卡片、日期、学习日志及练习进度。刷新默认回到词库，打开对应练习页继续。开始新轮次会覆盖该模式的旧轮次。

## 核心任务与成功标准（可复制到工作流表单）
1. **组织个人词库**：新建词书，添加包含四个字段的卡片，修改内容，使用搜索和筛选定位，再刷新。成功标准：内容、归属与保存结果一致，不误操作其他卡片；删除前说明范围，可取消。
2. **导入学习材料**：下载示例，分别尝试 CSV、JSON，查看预览后提交；尝试缺失释义及重复单词。成功标准：错误行有反馈、不写入；跳过和覆盖遵循正常规则，词书和计划不被意外改变。
3. **跨日学习与复习**：翻卡、选择熟练度、推进日期、查看今日/逾期卡片、再次作答。成功标准：各级间隔、同日重复和逾期计算均与规则一致，作答后进入下一张。
4. **拼写与重练**：输入拼写，完成一轮，查看正确率和错词，重练后再次查看。成功标准：判定遵循空格/大小写规则，题目反映最新卡片内容，错词状态随新结果更新。
5. **验证进度与数据恢复**：练习中刷新后继续，核对统计，取消并确认一次重置。成功标准：刷新恢复对应位置，统计口径一致；确认重置后日期、词书、卡片及日志恢复，取消不变。

## 已知限制与未完成功能
这是单用户、单浏览器本地版；没有登录、同步、发音、语音识别、AI 生成、数据导出、撤销或长期备份。没有多标签页并发合并机制，请只在一个标签页学习。清除站点存储会丢失数据。仅支持指定字段和 UTF-8 文件，不自动识别 Excel 文件或任意列名；每次导入最多 200 行。未做海量词库性能及浏览器存储配额测试；依赖浏览器允许本地存储。

## 设计、操作限制与重点测试范围
保持纯 HTML/CSS/JavaScript、本地资源和无构建启动方式；不要加入外部服务或真实账号。兼顾桌面与手机宽度，保留可见模拟日期、固定种子和确认重置入口。重点测试导入与编辑后的跨页一致性、日期边界、重复作答、错误后的计划、统计与持久化。不要只检查按钮是否可点。

## 额外验收要求
按核心任务连续操作，记录操作前后数据及模拟日期；每条独立流程先恢复初始数据。修复应保持其他功能和正常规则，刷新后也需成立；重复验证应得到相同结果。提交时根目录直接包含 index.html、style.css、app.js、README.md 和 examples，不需要安装依赖。
