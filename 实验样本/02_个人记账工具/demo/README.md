# 青禾账本 · 个人记账工具

用于学生和个人用户记录日常收支、核对月度现金结余与预算。无需账号，全部记录保存在当前浏览器的 localStorage。纯 HTML、CSS、JavaScript，图表为本地 SVG，无外部服务。

## 启动与重置

在本文件所在目录执行 `python -m http.server 8000 --bind 127.0.0.1`，浏览器访问 http://127.0.0.1:8000 。无需 npm 或安装依赖。请通过 HTTP 使用现代 Edge、Chrome 或 Firefox，不建议直接双击文件。

点击右上角“恢复初始测试数据”，阅读覆盖提示后确认；取消应保留全部数据。初始 8 条虚构记录分布于 2024 年 12 月、2025 年 12 月、2026 年 1 月和 2 月，包含 5 个分类和小数金额。默认统计月份为 2026-01，录入日期为 2026-01-15，与当天日期无关。测试前建议重置。

## 功能与业务规则

- 新增收入和支出，填写金额、分类、日期和备注；可编辑、确认删除、撤销最近一次删除。
- 分类为收入和支出共用；可创建、重命名，名称去除两端空格且不可重复，最多 20 字。重命名应同步历史记录。存在任意历史记录的分类不能删除；空分类可确认删除。
- 金额币种为人民币，范围 0.01～99,999,999.99 元，最多两位小数。无论收支都输入正数，由类型决定方向。备注可选，最多 200 字。
- 明细默认显示所有月份。关键词匹配备注或分类；类型、分类、起止日期按“同时满足”组合。日期包含两端，起始晚于结束时没有匹配记录。清空筛选应移除关键词、类型、分类和日期条件，但保留排序。
- 日期或金额可升序、降序排列。排序不应改变记录的身份。
- 月收入、月支出仅统计选定年和月；结余＝收入－支出。统计月份不限制明细。
- 汇总、预算、分类占比和日度变化均不受明细筛选影响。分类占比＝该类月支出÷全月支出；无支出时显示空状态。日度图按本月各日聚合收支。
- 预算按月份独立设置，范围 0～99,999,999.99 元，最多两位小数；0 表示未设置。剩余＝预算－月支出，收入不抵扣预算消耗；支出超过预算时显示超支金额。
- 撤销只恢复本次页面会话最近一次确认删除的完整记录，包括原日期、分类和金额；切换月份不应改变恢复内容。再次删除覆盖上一次撤销机会；成功撤销一次或刷新后失效。
- CSV 导出当前筛选与排序后的明细，字段为日期、类型、分类、金额、备注。中文、逗号和引号应能正确保留。新增、编辑、删除、分类及预算应在同一来源地址刷新后恢复。

## 核心任务与成功标准

1. **日常记账**：录入一笔 25.60 元餐饮支出，搜索备注，编辑为 30.60 元，再刷新。成功标准：仅目标记录变化，金额和月度统计保持一致。
2. **收入与查询**：新增一笔收入，组合类型、分类和日期条件，再清空筛选和排序。成功标准：结果符合全部条件，日期两端记录可见，汇总不随明细条件变化。
3. **预算与图表**：选择固定月份、设置预算、增加支出。成功标准：月支出、结余、剩余预算与分类、日度图反映同一组记录，刷新仍保留预算。
4. **分类与恢复**：新建及重命名分类，尝试删除有历史的分类，删除和撤销一条账目。成功标准：历史分类受保护，撤销恢复原始内容且不会重复增加。
5. **数据交付**：导出筛选结果，取消一次重置，再确认重置。成功标准：CSV 字段完整；取消不改变数据；确认后恢复固定 8 条记录。

## 已知限制及未完成功能

本版本无云同步、多设备同步、登录、多币种、银行连接、附件、周期记账和 CSV 导入。CSV 是导出报表，不提供一键导入恢复。没有多标签页实时协同与冲突合并，测试时只操作一个标签页。清除浏览器站点数据会删除账本；不同协议、主机或端口拥有不同的存储。私密模式或禁用站点存储不属于支持环境。图表没有悬停详情或点选筛选功能。

## 设计和操作限制

无需真实账号、真实账单或密码。仅使用虚构数据；同一来源地址连续操作，避免切换端口造成数据看似丢失。页面适配桌面与手机，窄屏表格可横向滚动。删除和重置使用页面内确认框；按取消或 Escape 应关闭而不变更数据。数据体量面向个人小型账本，未做大量数据分页和性能优化。

## 重点测试与额外验收

重点覆盖新增后查询、筛选或排序后编辑、修改收支类型、删除与撤销、跨月份查询、预算同步、分类名称一致性、刷新恢复及 CSV 内容。对金额用独立计算核对，不只比较页面内各处。测试 0、负数、三位小数、无匹配条件、空备注、中文和标点。需要检查桌面与手机宽度、键盘输入、确认取消路径，以及刷新和重置后重跑核心任务的可重复性。
